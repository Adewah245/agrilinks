# Contributing to Agro-Shield

First, thank you for your interest in contributing to **Agro-Shield**! 🌾

Our mission is to build technology that helps farmers reduce post-harvest losses, improve market access, and increase productivity.

We welcome contributions that improve the project, fix bugs, or introduce new features.

---

## Development Workflow

1. Fork the repository.
2. Create a new feature branch.

```bash
git checkout -b feature/your-feature-name
```

3. Make your changes.
4. Test your changes.
5. Commit your work.

```bash
git commit -m "Add: short description of feature"
```

6. Push your branch.

```bash
git push origin feature/your-feature-name
```

7. Open a Pull Request.

## Coding Standards

### Go

- Follow standard Go formatting (`gofmt`)
- Use meaningful variable names
- Keep functions small and focused
- Handle errors properly
- Write reusable code

### HTML/CSS

- Use semantic HTML
- Keep CSS organized
- Ensure responsive layouts
- Maintain accessibility where possible
