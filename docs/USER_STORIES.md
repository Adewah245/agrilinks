## Authentication

As a farmer,
I want to create an account,
so that I can securely manage my farm information.

As a farmer,
I want to log in,
so that I can access my dashboard.


## Dashboard

As a farmer,
I want to see all important information on one screen,
so that I can quickly understand the status of my farm.


## Storage Monitoring

As a farmer,
I want to monitor the storage condition of my harvested crops,
so that I can reduce spoilage.

As a farmer,
I want to receive recommendations when storage conditions become unsafe,
so that I can take action before my crops are damaged.


## Marketplace

As a farmer,
I want to list my harvested crops,
so that buyers can find me.

As a farmer,
I want to see interested buyers,
so that I can negotiate directly.


## Market Prices

As a farmer,
I want to view current market prices,
so that I know the best time to sell my crops.


## AI Assistant

As a farmer,
I want to ask farming questions,
so that I receive practical advice.

As a farmer,
I want recommendations about crop care and storage,
so that I can improve my harvest.


## Buyer

As a buyer,
I want to browse available produce,
so that I can purchase directly from farmers.

As a buyer,
I want to contact farmers,
so that I can negotiate purchases.


## Administrator

As an administrator,
I want to manage users,
so that the platform remains secure.

As an administrator,
I want to update market prices,
so that farmers receive accurate information.
